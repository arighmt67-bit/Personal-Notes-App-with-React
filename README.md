# Personal Notes App with React

A personal notes application built as a submission project for Dicoding Academy — Belajar Membuat Front-End Web untuk Pemula.

## Features
- Add and delete personal notes
- Archive and unarchive notes
- Search notes by title or content
- Notes grouped by month
- Responsive design

## Tech Stack
- React 19
- Vite
- JavaScript (ES Modules)
- CSS
